# Three.js Learning Playground

A simple project created to explore how Three.js work step by step. This is repository serves as a personal sandbox for understanding the basics of 3D on the web using Three.js

## 🎯 Purpose

This project exists to help me learn:

- How scenes, cameras, and renderers interact
- How objects and materials behave
- How lighting affects the scene
- How animations work in a render loop
- How to structure a small Three.js project
- How different Three.js features come together

## 📚 What I'm Learning

- Setting up a basic Three.js environment
- Adding objects to a scene
- Adjusting the camera and experimenting with movement
- Understanding lighting and shadows
- Loading textures and models
- Improving performance and organization as I go

## 🚀 Goals

- Get familiar with Three.js fundamentals
- Learn at a comfortable pace
- Build confidence before moving into advanced features
- Keep everything simple, clean, and easy to experiment with

## 🛠️ Tech Stack

- Three.js — core 3D library
- Vite — fast development server & bundler
- JavaScript / ES Modules
- HTML & CSS for basic structure
